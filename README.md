# Muaz Personal Counter

A simple, interactive passenger counter application built with HTML, CSS, and JavaScript.

This project was developed as part of my JavaScript learning journey. It helped me practise DOM manipulation, event listeners, JavaScript functions, variables, and updating HTML content dynamically.

## Preview

A minimal counter application with an obsidian-and-silver chessboard background and pumpkin-orange buttons.

## Features

- **Increment Counter:** Increase the passenger count with a button click.
- **Save Entries:** Save the current count to previous entries.
- **Automatic Reset:** Reset the counter to zero after saving.
- **Responsive Design:** Works across different screen sizes.
- **Custom UI:** Halloween-inspired pumpkin buttons and a dark chessboard aesthetic.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling, layout, gradients, and responsive design |
| JavaScript (Vanilla) | Counter logic, DOM manipulation, and event handling |
| Google Fonts | League Spartan and Inter typography |
